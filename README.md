# Looper Cat 🐾

Companion app for hardware loopers: see your memory slots, listen to them,
edit, upload and download loops — without the knob-scrolling ceremony.

Part of the **Felitronics** family by [Darwin's Cat](https://darwinscat.com).
Built on the file-format knowledge of [rc5cat](https://github.com/AliceLafox/rc5cat).

> Early development — not yet released.
