# v0.9 hardware QA checklist

One focused hour with the real pedal (RC-5, firmware Ver 1.10 build 0050)
before the DMG reaches anyone else. Every box is a behavior promised by the
[guide](../guide.md); anything that fails blocks the release.

Abbreviated from the full M2 matrix — the long-session soak runs separately.

## Setup

- [ ] Build from the release tag; About shows 0.9.0 + a clean (non-dirty) hash.
- [ ] Safety net first: Maintenance → Backup configs, plus a manual copy of
      the whole `ROLAND/` tree off the card.

## Connect lifecycle

- [ ] Connect from NORMAL mode: pedal shows "Connecting", volume mounts,
      table fills — no pedal-menu touches.
- [ ] Disconnect: volume unmounts, pedal returns to the looper screen, loops
      play on the pedal.
- [ ] Five Connect/Disconnect cycles in a row — no degradation, no ghosts.
- [ ] Manual STORAGE entry from the pedal menu is still picked up.
- [ ] Yank the USB cable while connected + idle → ghost banner, auto-cleanup,
      normal reconnect after replug.
- [ ] Yank while the player is playing → playback stops, banner, recovery.
- [ ] Pedal-side STORAGE exit (the #21 case): the app may not notice until
      the first real touch — verify that touch errors honestly into the ghost
      flow and nothing phantom-succeeds.

## Mutations

Run each against: an empty slot, an occupied slot, and slot 99. After the
batch, Disconnect and verify the results on the pedal itself — names, tempo,
one-shot behavior, audio.

- [ ] Rename (12 chars, edge characters the pedal display owns).
- [ ] One-shot toggle (verify the pedal actually plays once).
- [ ] Set tempo… (verify tempo + rhythm on the pedal match the music).
- [ ] Push WAV into an empty slot.
- [ ] Replace WAV in an occupied slot (the old loop lands in the app trash).
- [ ] Pull to folder (the pulled WAV plays).
- [ ] Trim (the trimmed loop plays gaplessly on the pedal — the Sprint 4 bar).
- [ ] Clear → Move to trash.
- [ ] Clear → delete outright.
- [ ] Swap: neighbors, 1 ↔ 99, occupied ↔ empty.

## Edges

- [ ] Near-full card: push refuses honestly, nothing corrupted.
- [ ] Doctor on a healthy pedal-written card: zero findings (release
      criterion 3 — the doctor never cries wolf).
- [ ] Clean junk after macOS has touched the card: AppleDouble gone, pedal
      boots clean.

## Family guard (#35)

- [ ] The real RC-5 card passes with no banners.

## Install (with the signed DMG)

- [ ] A clean account/machine: the DMG opens without right-click ceremony
      (notarization holds), drag to Applications, first launch, Connect —
      under a minute end to end (release criterion 2).
